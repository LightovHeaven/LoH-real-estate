# HAU REAL ESTATE

## 1. Giới thiệu dự án
Hệ thống quản lý và phân tích đầu tư bất động sản Đà Nẵng.

## 2. Mục tiêu
- Quản lý danh mục bất động sản.
- Theo dõi giá mua và giá bán.
- Quản lý doanh thu cho thuê.
- Theo dõi chi phí vận hành.
- Tính toán dòng tiền và ROI.
- Hỗ trợ phân tích đầu tư bằng AI.

## 3. Đối tượng sử dụng
Nhà đầu tư và môi giới bất động sản.

## 4. Định hướng phát triển
Xây dựng công cụ hỗ trợ quản lý tài sản,
phân tích hiệu quả đầu tư và ra quyết định
dựa trên dữ liệu thực tế.
